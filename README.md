# The Morning Letter
Daily household newspaper for Jonesboro and Brookland, Arkansas.
- `letters/YYYY-MM-DD/` : each day's `letter.pdf`, page images `pg-NN.png` and `comic.png`
- `letters/index.json` : list of all letters (newest last), for the app
- `scripts/`, `comic/` : the tools that build the letter
- `logs/` : story log and comic gag log (to avoid repeats)
Public repo: never store passwords, tokens, financial or personal data here.
